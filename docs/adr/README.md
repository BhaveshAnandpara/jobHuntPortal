# Architecture Decision Records

This folder holds ADRs for decisions that change or extend the locked
contracts under `docs/architecture/`. Owned by the architect agent
(`.claude/agents/architect-agent.md`), whose responsibilities include
"Architecture Decision Records" and "Approved/rejected contract changes."

No ADRs exist yet. When one is needed (a new shared type, event, topic, or
table; a breaking change to an existing contract), add it here as
`NNNN-title.md` following the existing numbering, rather than silently
changing `docs/architecture/*` in place — see
[overview.md](../architecture/overview.md#product-source-of-truth-vs-engineering-source-of-truth).
